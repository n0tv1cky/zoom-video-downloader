# Privacy Policy

Zoom Recordings Sync is a personal automation tool. It is used only by its
owner, on their own computer, with their own Google accounts.

## What it accesses

- **Google Drive** (own account): uploads class recordings to a folder the
  owner chose, and reads/writes only the files the tool itself created or
  copied there.
- **Gmail** (own account): sends the owner a sync report email.
- **Google Sheets** (read-only): reads a class-recordings sheet to find new
  sessions.

## What it stores

Sign-in tokens and sync state are kept only in a private folder on the
owner's own computer. Nothing is sent to any server run by the developer,
and no data is collected, sold, or shared with any third party.

## Google API data

Use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
